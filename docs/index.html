mkrfc

RFC management for engineering teams.

Create, list, and resolve RFCs from the terminal. Interactive TUI forms, sequential numbering, custom templates, status tracking. No framework, no config.

$ mkrfc new
  Template    default (built-in)
  RFC Title   Add async job queue
  Summary     Replace synchronous order processing with a queue-backed worker pool

✓ docs/rfc/0001-add-async-job-queue.md

Install

Go

go install github.com/flaticols/mkrfc@latest

Binary

GitHub Releases

Usage

mkrfc New RFC if none exist, else list all RFCs
mkrfc new Create a new RFC with interactive form
mkrfc list List all RFCs in a table
mkrfc list --status DRAFT Filter by status
mkrfc resolve Transition a draft RFC to accepted / rejected / superseded
mkrfc review Add a reviewer; optionally approve or reject
mkrfc templates List available templates
mkrfc llm Print compact LLM-friendly help in XML format

Features

Interactive TUI

Powered by charmbracelet/huh. Select template, enter title and summary — all from the terminal without leaving your workflow.

Auto Numbering

RFCs are sequentially numbered 0001-slug.md, 0002-slug.md. Numbers never collide even with gaps.

Status Lifecycle

Track RFCs through DRAFT → ACCEPTED / REJECTED / SUPERSEDED. Resolution appends a dated note to the file.

Custom Templates

Drop .md files into docs/rfc/.templates/. mkrfc new presents a picker when multiple templates exist.

Embedded Default

The default template is compiled into the binary via //go:embed. Works offline with zero setup.

Git-Aware Author

Auto-detects author name and email from git config and injects them into the RFC frontmatter.

YAML Frontmatter

Every RFC has structured YAML metadata: title, authors, reviewers, status, date, resolved_date, tags.

Optional Sections

mkrfc new presents a multi-select picker for optional sections. Only selected sections appear in the output — no TODO placeholders for skipped ones.

PR Auto-link

If gh is installed and the current branch has a PR, the PR URL is automatically injected into the RFC header and frontmatter.

Review & Approve

mkrfc review adds a reviewer to the frontmatter and optionally approves or rejects the RFC with a dated resolution note.

LLM Help

mkrfc llm prints a compact XML summary of all commands, frontmatter schema, template data, and behavior — designed for pasting into an AI context.

No Framework

Command dispatch is a plain switch on os.Args[1]. Two external dependencies: huh and yaml.v3.

Examples

List RFCs

$ mkrfc list
NUM     TITLE                                    STATUS    DATE        AUTHORS
------------------------------------------------------------------------------------------
0001    Add async job queue                      ACCEPTED  2024-03-10  Alice <alice@co>
0002    Migrate to PostgreSQL                    DRAFT     2024-03-15  Bob <bob@co>
0003    Deprecate legacy auth service            DRAFT     2024-03-20  Alice <alice@co>

Resolve a Draft

$ mkrfc resolve
  RFC       0002: Migrate to PostgreSQL
  Status    ACCEPTED
  Note      Approved in architecture review, migration planned for Q2

✓ docs/rfc/0002-migrate-to-postgresql.md resolved as ACCEPTED

Custom Templates

$ ls docs/rfc/.templates/
lightweight.md

$ mkrfc new
  Template    ● default (built-in)
              ○ lightweight
  RFC Title   Cache invalidation strategy
  Summary     Proposal for a unified cache eviction policy

✓ docs/rfc/0004-cache-invalidation-strategy.md
